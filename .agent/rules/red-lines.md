# 项目红线与强制工作流规则（Red Lines）

本项目所有后续设计与实现工作必须无条件遵守以下规则：

1. **严禁编造标准数据**：不许编造任何标准数据（灵敏度因子、标准峰位、物性参数）；内置默认值必须可编辑，并在界面标注为经验默认值。
2. **拟合必带误差与残差**：一切拟合必须同时输出参数误差和残差图。
3. **全参数可见可改**：所有处理参数在界面可见可改，不许黑箱。
4. **合成数据真值自检**：每个模块必须用自生成的合成数据验证精度，报告实测误差。
5. **独立工作树隔离**：子任务在独立工作树里做，互不覆盖文件。
6. **逐模块浏览器实操自测与截图存档**：进入实现阶段后，每完成一个模块，必须用浏览器工具（`preview_*`）实际打开页面操作一遍自测，并将截图存档至项目 `qa-screenshots/` 目录；如果浏览器工具不可用或出错，立刻在本线程明确说明，严禁跳过。
